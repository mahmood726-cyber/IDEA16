### Key Takeaway Box (Web)

```
┌─────────────────────────────────────────────────────────────────┐
│ 🔑 KEY POINT                                                     │
│                                                                  │
│ DANISH showed that ICDs reduce sudden death but DON'T improve   │
│ overall survival in modern heart failure patients.              │
│                                                                  │
│ This was tested BEFORE ARNi and SGLT2i became standard.         │
│ The benefit today is likely even smaller.                       │
│                                                                  │
│ This is the ICD equivalent of aspirin's negative trials         │
│ (ARRIVE, ASCEND, ASPREE).                                       │
└─────────────────────────────────────────────────────────────────┘
```

**Caption**: The DANISH trial (2016) enrolled 1,116 patients with non-ischemic heart failure before modern medications (ARNi, SGLT2i) became standard. While ICDs cut sudden death in half (8.2% to 4.3%), overall mortality was unchanged (23.4% to 21.6%, P=0.28). Patients saved from sudden death appeared to die from other causes instead—a phenomenon called "competing risks." If ICDs showed no survival benefit even before today's better medications, the benefit in 2025 is likely smaller still.

## Design Notes for Web Publication

### Figure 1 (Aspirin-ICD Parallel):
- **Format**: Simple two-column table or side-by-side timeline
- **Colors**:
  - Aspirin column: Blue
  - ICD column: Red
  - Checkmarks: Green
  - X marks: Red
  - Question marks: Yellow
- **Mobile-friendly**: Stack columns vertically on small screens
- **Accessibility**: Clear icons (✅ ❌ ❓) plus text

### Figure 2 (DANISH Results):
- **Format**: Two horizontal bar charts (Panel A and B)
- **Colors**:
  - No ICD bars: Gray
  - With ICD bars: Blue
  - Panel A (success): Light green background
  - Panel B (failure): Light yellow/orange background
- **Annotations**: Large text showing percentages
- **Mobile-friendly**: Bars stack vertically on phones
- **Accessibility**: Exact percentages in text, not just visual

### Both Figures:
- **Total size**: Each ~600px wide for web
- **File format**: SVG (scalable) or high-res PNG
- **Alt text**: Comprehensive descriptions for screen readers
- **Inline data**: All key numbers visible without clicking
- **Social media ready**: Square versions (1:1 ratio) for Twitter/LinkedIn
